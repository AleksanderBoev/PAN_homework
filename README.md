# PAN_homework
репозиторий для работ по ПАН Боева.  
Каждая задача написанна отдельным файлом: ex + номер дз + номер задачи + .cpp, дополнительно сгрупированны по дирректориям.  
build.sh - скрипт для удобной компиляции. Каждый файл компилируется в дирректорию bin, с таким же именем, но без расширения.  
** взможно сделаю библиотечный файл/каталог pan_common с полезными функциями из разных задач.
